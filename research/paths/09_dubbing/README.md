# Path 09 — Dubbing

**Status:** future

## Goal

Dub films: translated text + the original actor's audio as the reference for voice and style.

## What already exists

Portuguese synthesis with pitch and speed taken from a reference (README, section 1).

## What is missing

- Copying the actor's voice, which is the subject of paths 01–08.
- Controlling the duration of each line so it fits the scene.
- Using the video (mouth movement) and lip sync.

In dubbing there is a lot of the actor's audio without aligned transcriptions. That favors the paths that use several references and voice conversion ([R07](../../results/R07_multiple_references.md), [path 07](../07_voice_augmentation/README.md)).
